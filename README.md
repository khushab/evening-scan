# Evening Scan dashboard

A read-only snapshot of a personal research app for Indian stocks (NSE and BSE), published from a Mac after each
evening scan: the market check, the Setup E checks, the delivery-dip and ML lists, SME breakouts and paper trades.

Live page: https://khushab.github.io/evening-scan/

**Research and paper-trading only, not investment advice.** The code and the market data live in a private repository.
